## Proyectos destacados

### DulceCuentas — Plataforma de autogestión financiera
Aplicación web orientada a la gestión financiera, inventario y pedidos para artesanas dulceras de El Carmen de Bolívar.

**Aportes y características:**
- Gestión multi-tienda con datos independientes por emprendimiento.
- Registro de ventas y gastos, control de caja y exportación de reportes en CSV.
- Control de inventario con alertas de disponibilidad y gestión de encargos.
- Modelo de datos en Supabase/PostgreSQL y visualización analítica con Chart.js.

**Tecnologías:** HTML5, Tailwind CSS, JavaScript (ES6+), Supabase, PostgreSQL, Chart.js.  
**Repositorio:** [github.com/jhoning-21/dulcecuentas](https://github.com/jhoning-21/dulcecuentas)

### ManttoPro — Sistema CMMS
Plataforma para gestión de mantenimiento industrial con arquitectura distribuida.

**Aportes y características:**
- Frontend con React 18, TypeScript y Vite.
- Backend con microservicios en Node.js/Express y API Gateway.
- Persistencia con PostgreSQL (aislada por servicio) y mensajería con RabbitMQ.
- Orquestación con Docker Compose.

**Tecnologías:** React, TypeScript, Node.js, Express, PostgreSQL, RabbitMQ, Docker.

### HelpDesk Pro — Gestión de tickets
Aplicación web para administración de tickets de soporte técnico.

**Aportes y características:**
- Separación entre capa de servicios HTTP y lógica de interfaz.
- Operaciones CRUD asíncronas con `fetch` y `async/await`.
- Búsqueda, filtrado e indicadores en tiempo real en el cliente.

**Tecnologías:** HTML5, CSS3, JavaScript, REST API.

## Cómo visualizar el portafolio

1. Abre la carpeta `C:\Users\User\Desktop\Portafolio`.
2. Ejecuta `index.html` en tu navegador web.
3. Para una mejor experiencia de desarrollo, también puedes usar una extensión como Live Server en VS Code.
