## Proyectos destacados

### DulceCuentas — Plataforma de autogestión financiera
Plataforma web para la gestión financiera, inventario y pedidos de emprendimientos de artesanas dulceras en El Carmen de Bolívar.
- Gestión multi-tienda, registro de ventas y gastos, control de caja y exportación CSV.
- Control de inventario, alertas de disponibilidad y seguimiento de encargos.
- Integración con Supabase/PostgreSQL y visualización con Chart.js.

Repositorio: [github.com/jhoning-21/dulcecuentas](https://github.com/jhoning-21/dulcecuentas)

### ManttoPro — Sistema CMMS
Sistema de gestión de mantenimiento industrial con enfoque en arquitectura distribuida.
- Frontend con React 18, TypeScript y Vite.
- Microservicios en Node.js/Express con API Gateway.
- PostgreSQL por servicio, RabbitMQ y despliegue con Docker Compose.

### HelpDesk Pro — Gestión de tickets
Aplicación web para soporte técnico con operaciones CRUD y consumo de API REST.
- Separación de responsabilidades entre servicios HTTP e interfaz.
- Búsqueda, filtrado e indicadores en tiempo real.
